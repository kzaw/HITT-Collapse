Training Journal v2

Updates:
- Strength blocks increased from roughly 10 minutes to 15–20 minutes on strength days.
- Week 5 test-day strength windows are now 20 minutes.
- Marking a workout Done automatically collapses that day.
- Every day also has a manual Expand / Collapse button.
- Existing v1 journal data is migrated automatically when possible.
- Offline cache version bumped so GitHub Pages updates more reliably.

To update your GitHub Pages site:
1. Unzip this package.
2. Upload and replace index.html and service-worker.js in the existing repository.
3. You may also replace manifest.webmanifest, README.txt, and the icons folder, although the icons are unchanged.
4. Commit directly to main.
5. Wait for GitHub Pages to redeploy.
6. On iPhone, fully close the Training Journal app and reopen it.
7. If the old version still appears, open the GitHub Pages URL in Safari, refresh once, then reopen the Home Screen app.

Workout data remains stored locally on the iPhone, not in GitHub.
